# Projet Open Source — OpenClassrooms

Travail réalisé dans le cadre du cours **"Utilisez Git et GitHub pour vos projets 
de développement"** sur OpenClassrooms.

## Objectif
Apprendre à contribuer à un projet open source en utilisant Git et GitHub :
- Fork d'un dépôt existant
- Création de branches
- Pull requests
- Collaboration en équipe
